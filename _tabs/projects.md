# Projects

This is a collection of practical cybersecurity and software engineering projects.

## Cyber Incident Command Simulator

A defensive incident-response simulation platform that models a security incident from detection through investigation, response, and reporting.

**Stack:** Python, FastAPI, SQLite, HTML, CSS, JavaScript, pytest

### Current capabilities

- Synthetic security event generation
- Detection rules
- Attack-chain correlation
- Incident investigation workflow
- Persistent findings and response actions
- Incident status management
- Automated tests
- HTML incident-report export
